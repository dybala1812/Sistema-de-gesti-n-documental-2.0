# Prompt Reutilizable: Revisión de Contenido

Revisa el contenido visible de {{PROYECTO}} como editor experto en el dominio y en UX writing.

Objetivos:

- Detectar errores de contenido o de dominio.
- Mejorar la claridad para {{USUARIOS}}.
- Unificar terminología (heurística H4) y usar el lenguaje del usuario (H2).
- Detectar problemas de codificación de caracteres.
- Revisar mensajes de error y ayudas según H9 y H10 de `ux-heuristicas`.

Salida esperada:

- Hallazgos principales con severidad.
- Correcciones concretas (texto actual → texto propuesto).
- Temas que requieren validación manual.
